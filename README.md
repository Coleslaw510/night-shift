# Night Shift (v1.1)

Work the night shift at a creepy little 24-hour supermarket. Ring people up, make change,
restock the shelves, and take the trash out to the dumpster. (Single player for now.)

## Controls
- WASD move · Mouse look · Shift sprint · Space jump
- E or left-click: use / scan. **Hold** E on a shelf spot to stock it from a box.
- Q: put a stock box back · Esc: pause (settings are in the pause menu)

## Windows
1. Unzip `NightShift-1.1.1-Windows.zip`.
2. Double-click `NightShift.exe`. If SmartScreen warns you, click **More info → Run anyway**.

## Mac
1. Unzip `NightShift-1.1.1-Mac.zip` to get `Night Shift.app` (drag it to Applications if you like).
2. The first time, **right-click the app → Open → Open** (macOS blocks unsigned apps otherwise).
3. If macOS says the app is "damaged", open Terminal and run:
   `xattr -dr com.apple.quarantine "/path/to/Night Shift.app"`
   (tip: type `xattr -dr com.apple.quarantine ` then drag the app into the Terminal window).
